# Translations (i18n)

- Config: `src/i18n/index.ts` — language: `en` (English only)
- Locale file: `src/i18n/locales/en.json`

## IMPORTANT Rules

1. **No hardcoded text** — every user-facing string uses `t()`. This includes labels, placeholders, button text, headings, descriptions, select options, table headers, status labels, and error messages.
2. **No inline fallbacks** — never `t('key', 'fallback')`. Fallback is set in i18next config.
3. **`en.json` is source of truth** — define all copy there.
4. **Key format**: `snake_case` — ALWAYS. Every key in `en.json` and every string passed to `t('...')` must be `snake_case`. **Never camelCase in i18n keys**, even if the corresponding TypeScript form field is camelCase. Example: form field `organizationName` → i18n key `settings.organization.organization_name`.
5. **Select "all" option**: use `{t('common.all')}` — never repeat the filter name.

## Enum Translations

Centralized under the `enums` namespace — never inside page-specific keys.

- Labels: `enums.{enum_snake_case}.{value}` → e.g. `enums.issue_severity.critical`
- Descriptions: `enums.{enum_snake_case}.descriptions.{value}` → e.g. `enums.framework_alignment_status.descriptions.aligned`

```tsx
// ❌ Bad
t('vendor_detail.overview.severity.critical')

// ✅ Good
t('enums.issue_severity.critical')
t('enums.framework_alignment_status.descriptions.aligned')
```

## Examples

```tsx
// ❌ Bad
<h1>Vendor library</h1>
<Input placeholder="Search vendors" />
t('auth.sign_in.title', 'Sign in')

// ✅ Good
<h1>{t('vendor_library.title')}</h1>
<Input placeholder={t('vendor_library.search_placeholder')} />
t('auth.sign_in.title')
```

## en.json Structure

```jsonc
{
  "enums": {
    "issue_severity": { "critical": "Critical", "high": "High" },
    "framework_alignment_status": {
      "aligned": "Aligned",
      "descriptions": {
        "aligned": "No issues detected during the assessment.",
      },
    },
  },
}
```

## Adding a New Enum

1. Add enum to GraphQL schema, run `yarn gql`
2. Add translations under `enums.{enum_name_snake_case}` in `en.json`
